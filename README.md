# 🗺️ 校园生活指南 · 山西师范大学

校园地图导览项目：**微信小程序 + Web 网页版**，同一套点位数据，双端共用。

## 🌐 在线体验（Web 版）

👉 **https://eznine.github.io/webgis/**

- 全屏地图（腾讯官方瓦片，GCJ-02 坐标系）
- 86 个实地采集点位，10 大分类（餐厅 / 小吃饮品 / 教学楼 / 宿舍 / 快递 / 超市 / 浴室 / 办公楼 / 体育 / 其他）
- 搜索 + 分类胶囊筛选 + 距离排序
- 玻璃拟态 UI：搜索栏 / 分类胶囊 / 底部抽屉（可下拉收起）/ 选点卡 / 悬浮按钮
- **纯文字标注层**：底图标注不可信，由自家数据做"地面真值"——不画大头针，86 个点位全部以白描边文字显示；**单一缩放门槛**：16 级起 86 个字全部一起出现（不分批、无优先级，可直接改 `LABEL_MIN_ZOOM`），可一键开关
- **纠错说明**：选点卡展示 `note` 字段（新建 / 更名 / 合并 / 待复核），告诉用户"你比地图新在哪"
- 一键跳转腾讯地图导航

## 📱 微信小程序版

小程序代码独立维护（微信开发者工具 + 云开发模板），功能与 Web 版一致并额外支持：

- 原生定位（GCJ-02 无偏移）+ `wx.openLocation` 一键导航
- 餐厅 / 排行榜 / 教室分布等扩展页（数据完善中，当前显示「敬请期待」）

## 🛠️ 数据维护

`docs/campus-data.js` 是 Web 版唯一数据源，结构：

```js
{ id, name, category, lat, lng, desc, major?, note? }
```

可选字段：

- `major: true` → 地标（餐厅 / 教学楼 / 操场等），当前纯文字模式下不分级，此字段保留备用（如以后做缩放门控）
- `note: "..."` → 纠错说明，随选点卡展示：标记 新建 / 更名 / 合并 / 待复核，底图没更新或写错的地方都写在这里

新增点位：按 ID 分段规划追加（100-199 宿舍/浴室/快递/超市 | 200-299 餐厅/小吃 | 300-399 教学楼 | 400-499 办公/体育/其他 | 500+ 新增），坐标使用 GCJ-02（腾讯/高德拾取器采集）。
