# 🗺️ 校园生活指南 · 山西师范大学

校园地图导览项目：**微信小程序 + Web 网页版**，同一套点位数据，双端共用。

## 🌐 在线体验（Web 版）

👉 **https://eznine.github.io/webgis/**

- 全屏地图（腾讯官方瓦片，GCJ-02 坐标系）
- 87 个实地采集点位，10 大分类（餐厅 / 小吃饮品 / 教学楼 / 宿舍 / 快递 / 超市 / 浴室 / 办公楼 / 体育 / 其他）
- 搜索 + 分类胶囊筛选 + 距离排序
- 玻璃拟态 UI：搜索栏 / 分类胶囊 / 底部抽屉（可下拉收起）/ 选点卡 / 悬浮按钮
- 水滴形分类大头针 + 点位名称标注（可开关）
- 一键跳转腾讯地图导航

## 📱 微信小程序版

小程序代码独立维护（微信开发者工具 + 云开发模板），功能与 Web 版一致并额外支持：

- 原生定位（GCJ-02 无偏移）+ `wx.openLocation` 一键导航
- 餐厅 / 排行榜 / 教室分布等扩展页（数据完善中，当前显示「敬请期待」）

## 📁 目录结构

```
├── docs/               ← Web 版源码（GitHub Pages 发布目录）
│   ├── index.html      ← 全部 UI + 交互逻辑（Leaflet 1.9）
│   ├── campus-data.js  ← 点位数据（与小程序 campus.js 同源）
│   └── pins/           ← 分类水滴大头针图标
└── README.md
```

## 🛠️ 数据维护

`docs/campus-data.js` 是 Web 版唯一数据源，结构：

```js
{ id, name, category, lat, lng, desc }
```

新增点位：按 ID 分段规划追加（100-199 宿舍/浴室/快递/超市 | 200-299 餐厅/小吃 | 300-399 教学楼 | 400-499 办公/体育/其他 | 500+ 新增），坐标使用 GCJ-02（腾讯/高德拾取器采集）。

## 🧭 技术选型

| 能力 | 选型 |
|---|---|
| Web 地图引擎 | Leaflet 1.9（CDN 引入，零构建） |
| 底图瓦片 | 腾讯官方瓦片服务（styleid=3） |
| 小程序地图 | 微信原生 map 组件 |
| 导航 | 小程序 `wx.openLocation` / Web 腾讯地图 URI API |
| UI 风格 | 玻璃拟态（backdrop-filter 毛玻璃） |
